# OllyGarden Brand Kit

The OllyGarden brand guideline, logos, fonts, icons and photography, ready to download,
for partners, agencies and anyone building something with the OllyGarden name on it.

**Live page:** https://ollygarden.github.io/brand-kit/

This is a single static page (`index.html`) served by GitHub Pages. The downloads live in
Google Drive and in the Icon and Photo libraries; this page points to them.

It is the external edition of the internal Design Hub, with internal material left out.
When brand assets change, update both. Tracked in Linear as D-258.
